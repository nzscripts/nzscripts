# 🎮 Minecraft Forge 1.12.2 — Nazzy Story Modes Server Installer

Автоматический установщик и менеджер выделенного сервера **Minecraft Forge 1.12.2** для прохождения сюжетных карт и режимов от **Nazzy** (Laboratory, Slasher, Phasmophobia, Operation Blizzard, Infected, Crossbattle, Scavenger) для совместной игры через **Radmin VPN** или локальную сеть.

---

## ⚡ Быстрая установка в 1 команду

Нажмите `Win + R` на клавиатуре и вставьте команду (или выполните её в терминале **PowerShell**):

```powershell
powershell -NoExit -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nzscripts/nzscripts/refs/heads/main/script.ps1 | iex"
```

> [!TIP]
> Команда автоматически проверит наличие **Java 8 (64-bit)** (по алгоритмам Prism Launcher), развернёт ядро Forge 1.12.2, выведет интерактивное меню выбора режима (1–7), отфильтрует несовместимые клиентские моды, установит сюжетную карту, настроит `server.properties` (включая лимит игроков `max-players`) и сгенерирует готовый `start.bat`.
> При запуске через `Win + R` сервер автоматически разворачивается на Рабочем столе в папке `Desktop\NazzyServer`.

## 📐 Стандарты разработки и качество кода
Скрипт полностью разработан в соответствии со стандартами [PowerShell Practice and Style Guide (PoshCode)](https://github.com/PoshCode/PowerShellPracticeAndStyle):
- **Одобренные глаголы и единственное число сущностей:** `Find-PrismJavaInstallation`, `Initialize-ForgeBase`, `Expand-ArchivePackage`, `Set-ServerConfiguration`, `Install-StoryMode`.
- **Никаких псевдонимов (No Aliases):** Используются исключительно полные имена командлетов (`Where-Object`, `Select-Object`, `Get-ChildItem`, `Copy-Item`, `Remove-Item`, `New-Item`, `Test-Path`).
- **Нулевой оверхед конвейера:** Замена `| Out-Null` на производительные конструкции `$null = ...` и `[void]`.
- **Строгая безопасность сравнений:** `$null` всегда слева (`$null -eq $var`, `$null -ne $var`).
- **Отсутствие хардкода путей:** Все пути вычисляются динамически через `${env:UserProfile}`, `[Environment]::GetFolderPath('Desktop')` и `$env:TEMP`.
- **Встроенная документация (CBH):** Полные блоки `.SYNOPSIS`, `.DESCRIPTION`, `.PARAMETER`, `.EXAMPLE`, `.OUTPUTS`, `.NOTES`.
- **One True Brace Style (OTBS):** Единый отступ в 4 пробела и корректная расстановка фигурных скобок.

## 📖 Полное досье и правила сюжетных режимов Nazzy

### 1. 🧬 LABORATORY NZ (Комплекс "D7")
* **Версия:** Forge 1.12.2
* **Рекомендуемый состав:** 8 игроков (`max-players=8`)
* **Сюжет:** В секретном исследовательском комплексе «D7» тайной корпорации «Netherhill» произошло катастрофическое нарушение условий содержания. Персонал заблокирован, реактор нестабилен, а по отсекам рыщет опаснейший биологический объект.
* **Роли и задачи участников:**
  * 🧪 **Специалисты:** Обычные выжившие сотрудники комплекса. Задача — скоординироваться, найти способ открыть аварийные шлюзы и сбежать из комплекса живыми.
  * 🛡️ **Оперативники CSG:** Элитная штурмовая группа быстрого реагирования. Вооружившись винтовками и тактической бронёй CSG, оперативники должны выполнить боевой приказ: зачистить Специалистов, ликвидировать опасного Монстра и нормализовать работу главного Реактора.
  * 👹 **Объект «NH-67B»:** Смертоносный мутант невероятной силы. Задача — разорвать всех людей в клочья и не допустить восстановления контроля над комплексом.
* **Особенности:** Арсенал оружия и брони `ModularWarfare`, сюжетные ключ-карты допуска.

* **Версия:** Forge 1.12.2
* **Рекомендуемый состав:** 5 игроков (`max-players=5`)

  * 🏃 **Выжившие (4 игрока):** Исследовать территорию лагеря, координировать действия по голосовому чату, выполнять задания по починке генераторов/поиску ключей и найти способ совершить побег.
  * 🪓 **Маньяк / Тварь (1 игрок):** Использовать ночной полумрак и знание территории, чтобы выслеживать людей, нападать из засады и уничтожить всех до того, как они сбегут.
* **Особенности:** Голосовой чат с пространственным звучанием, система квестов побега, атмосфера классических слэшеров.

## 🛠️ Что делает установщик под капотом

1. **Детект Java 8 (64-bit):**
   - Сканирует реестр Windows, пути лаунчеров (Prism Launcher `JavaChecker`/`JavaUtils`), переменные среды и Program Files.
   - Фильтрует 64-битные среды Java 8, гарантирующие стабильность Forge 1.12.2.
2. **Развёртывание Forge 1.12.2 (билд 2860):**
   - Кэширует чистое ядро и библиотеки в `%USERPROFILE%\.mc_forge_base_1.12.2`.
   - Автоматически скачивает патч `asm-debug-all-5.2.jar` (решает ошибку 404 Forge Maven) и библиотеку `launchwrapper-1.12.jar`.
3. **Фильтрация клиентских модов:**
   - Автоматически исключает `OptiFine`, `BetterFoliage` и `tlskincape`, предотвращая падение сервера с `NoClassDefFoundError: GuiScreen`.
4. **Контент-паки оружия (`ModularWarfare`):**
   - Автоматически выносит папку с оружием и прототипами в корень сервера, строго вне папки карты.
5. **Авто-конфигурация мира и `server.properties`:**
   - Рекурсивно находит `level.dat`, переносит мир и прописывает имя в `level-name`.
   - Задаёт оптимальный `max-players` под выбранный сюжетный режим.
   - Выставляет `online-mode=false` (для пираток и лаунчеров без лицензии), `enable-command-block=true`, `allow-flight=true`, `spawn-protection=0`, `gamemode=2`.
6. **Автоподтверждение FML:**
   - В `start.bat` прописан флаг `-Dfml.queryResult=confirm`, чтобы сервер не зависал на ожидании ручной команды `/fml confirm`.
7. **Ресурспаки:**
   - Извлекает клиентские ресурспаки в папку `resourcepacks/`, чтобы хост мог быстро передать их друзьям.

## 🌐 Как играть с друзьями через Radmin VPN

### 1. Хост (тот, у кого запущен сервер):
1. Скачайте и установите [Radmin VPN](https://www.radmin-vpn.com/).
2. Создайте сеть (например, `Nazzy-Story-Server` с паролем).
3. Запустите установку через скрипт и выберите желаемый режим.
4. Запустите сервер двойным кликом по [`start.bat`](start.bat).
5. Скопируйте свой IP в Radmin VPN (например, `26.154.88.12`).

### 2. Друзья (клиенты):
1. Подключаются к вашей сети в Radmin VPN.
2. Запускают свой лаунчер Minecraft Forge 1.12.2 с модами выбранного режима (и ресурспаком из папки `resourcepacks`).
3. В игре выбирают **Сетевая игра** ➔ **По адресу** ➔ вводят ваш IP из Radmin VPN: `26.154.88.12:25565`.
4. Голосовой чат **ModularVoiceChat** (порт `7656 UDP`) подключается автоматически через Radmin VPN без дополнительной настройки роутера.

## 🚀 Параметры запуска для автоматизации

Скрипт поддерживает запуск с параметрами напрямую:

```powershell
# Автоматическая установка режима Laboratory с 6 ГБ ОЗУ
powershell -ExecutionPolicy Bypass -File setup.ps1 -Mode Laboratory -MaxRamGB 6 -MinRamGB 2 -Force

# Неинтерактивная установка через сеть
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/nzscripts/nzscripts/refs/heads/main/script.ps1))) -Mode Slasher -MaxRamGB 4 -Force
```
